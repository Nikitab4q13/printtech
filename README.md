# ПринтТех

Адаптивный многостраничный сайт-визитка для сервисной компании «ПринтТех» в Калининграде.

## Стек

Чистые HTML, CSS и JavaScript выбраны для статичного сайта: нет сборки, зависимости отсутствуют, страницы быстро открываются на хостинге и легко редактируются. Формы сейчас демонстрационные: перед публикацией подключите Formspree или собственный HTTPS-бэкенд.

## Локальный запуск

Откройте `index.html` через Live Server в VS Code или выполните из каталога проекта:

```text
python -m http.server 8000
```

Затем откройте `http://localhost:8000`.

## Публикация

Подойдут GitHub Pages, Netlify, Vercel или обычный статичный хостинг с HTTPS. При подключении домена замените адрес в `sitemap.xml`, настройте DNS и включите автоматический SSL-сертификат.

## Перед запуском

- Подключить реальный обработчик формы, серверную валидацию, CSRF-токен и honeypot или reCAPTCHA.
- Проверить HTTPS, заголовки Content-Security-Policy, X-Content-Type-Options и Referrer-Policy.
- Уточнить актуальность групп VK и добавить рабочие ссылки WhatsApp/Telegram.
- Проверить номер телефона, адрес, цены и текст акций у владельца.
- Сжать изображения и при необходимости добавить WebP/AVIF в `picture` с `srcset`.
- Проверить Lighthouse, клавиатурную навигацию, контраст и форму на iPhone SE, iPhone 14 и Android среднего класса.
- Заменить `printtech39.ru` в `sitemap.xml` на фактический домен.
